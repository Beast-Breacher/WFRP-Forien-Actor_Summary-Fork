# Forien's Actors Summary — compatibility fork

Небольшое обновление оригинального модуля Forien 0.1.3-beta. Модуль показывает ведущему сводку выбранных персонажей: предметы, навыки и другие записи через фильтры, а также значения атрибутов. Исходный интерфейс Svelte, формат настроек, API и компендий пресетов сохранены.

Версия форка: **0.1.4-beta.2**. Репозиторий: [Beast-Breacher/WFRP-Forien-Actor_Summary-Fork](https://github.com/Beast-Breacher/WFRP-Forien-Actor_Summary-Fork).

## Совместимость

Целевой диапазон — **Foundry VTT 11–14**, включая актуальную стабильную **14.369** на 3 ноября 2026 года. Для 11–12 сохранена старая панель управления; для 13–14 добавлены новые формат панели и пространства имён API. Переход на ApplicationV2 не выполнялся: Foundry 14 ещё предоставляет ApplicationV1, на котором построен исходный интерфейс.

**Проверено в запущенной Foundry 14.369 с WFRP4e 10.1.2**, в тестовом мире `waha-test`: окно сводки и настройки, перетаскивание, фильтры, обновление данных, число колонок, кнопка панели, чтение компендия, удаление персонажа и освобождение подписок. Прошли 16 автотестов. Манифест: `minimum: 11`, `verified: 14.369`, `maximum: 14`. Ядра 11–13 отдельно не запускались: поддержка сохраняется исходным API и проверяемыми адаптерами. Совместимость с 10 и ниже не заявляется: оригинал уже требовал 11.

Модуль системно независимый. Пути полей и JavaScript в пресетах зависят от игровой системы и могут требовать отдельных поправок после её обновления. Это относится и к WFRP4e; версия ядра Foundry сама по себе не гарантирует неизменность полей персонажа.

## Использование

1. Установите и включите модуль через **Manage Modules**.
2. Войдите ведущим. Откройте сводку кнопкой с группой людей в инструментах токенов. По умолчанию окно открывается при входе в мир.
3. Перетащите персонажей из списка Actors в окно сводки.
4. Шестерёнка открывает настройки: 1–6 персонажей в строке, фильтры предметов и атрибутов.
5. Правая кнопка на заголовке персонажа или предмете открывает его лист. Кнопки карточки сворачивают её или удаляют из сводки; документ персонажа при этом не удаляется.

Пример атрибута: `system.details.species.value|Вид`. Пример фильтра предметов: `item.type === "skill"`. Пути уточняйте по модели вашей игровой системы. JavaScript callbacks — сохранённая функция оригинального модуля; выполняйте только проверенные пресеты.

Перетаскивание принимает персонажей мира (`Actor.<id>`). Персонажа из компендия сначала импортируйте в Actors. Настройки сводки и список персонажей общие для мира; положение и сворачивание окна сохраняются в сессии браузера.

Для макросов сохранён API:

```js
const api = game.modules.get("forien-actors-summary").api;
api.renderApp();
api.renderConfig();
// api.closeApp();
// await api.toggleApp(true);
```

## Обновление с оригинала

В 0.1.4-beta.2 заголовок окна сводки сделан белым. Проверенная версия ядра — **14.369**. Если Foundry продолжает показывать «проверено на версии 11», завершите игровой мир, обновите модуль на экране настройки Foundry и перезапустите сервер Foundry. Одного обновления вкладки браузера недостаточно для перечитывания манифеста, изменённого на диске при работающем сервере.

Сохранён ID `forien-actors-summary`, поэтому существующие настройки подхватываются без миграции. Для локальной установки распакуйте готовый ZIP в `Data/modules/forien-actors-summary`, затем перезапустите Foundry. Оригинал и форк с одинаковым ID одновременно не устанавливаются как разные модули.

## Исправления и сборка

Исправлены новая панель инструментов, обращения к перемещённым API, некорректный drag-and-drop, пропавшие персонажи, утечка подписок документов, пустые дополнительные поля, отсутствующая RegExp-группа, вложенные массивы и булевы атрибуты. Число колонок ограничено поддерживаемыми CSS значениями.

В исходном скомпилированном JavaScript точечно изменены прикладной код и адаптер сохранения настроек; существующий Svelte/TRL интерфейс сохранён. Маленький файл `compatibility.js` содержит адаптеры. Неверная после правок JS source map удалена; CSS и его source map не изменялись. Отдельного дерева исходников и конфигурации сборки в архиве не было. Исходная JS source map содержит встроенные исходники и сохранена отдельно в `tools/upstream/` для справки; она относится к версии 0.1.3-beta и не подключается к изменённому коду. Полноценная пересборка Svelte здесь не заявляется. `tools/release.mjs` воспроизводимо упаковывает готовые файлы и генерирует согласованный манифест.

```powershell
node --test tests/*.test.mjs
node tools/release.mjs
```

Нужен Node.js 22+ только для разработки и сборки. Для использования в Foundry Node.js отдельно устанавливать не нужно. В `dist/` будут ZIP и `module.json`.
